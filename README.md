# Beep Campus
One static file (`index.html`). No server, no API key, no cost.

Deploy free: GitHub Pages (upload files > Settings > Pages > main / root) or Vercel/Netlify.

## What it does
- Learning path: 6 Digital Marketing topics, lesson + 2-question quiz, star + points. Start order matches your level (12th / UG / PG / working).
- Home: one "Do this now" card + a 4-step strip (Read, Quiz, Earn star, Assessment).
- Assessment: open any time, nothing locked, nothing to pay. Pass with 50%+ for a free certificate. Retake to improve.
- Community (Reddit-style): channels (Internships, Projects, Doubts, Resources), create posts with optional link, upvote/downvote, comments, sort Hot/New/Top, "Get a hint" on Projects/Doubts. Four labelled sample posts are pre-loaded.
- Beep Buddy chatbot: instant answers about the app and the course; optional free on-device AI tutor (WebLLM, ~400 MB, Chrome/Edge with WebGPU).

## Honest limits
Progress and posts are stored in the browser (localStorage). Posts are not shared between different users/devices. Sharing would need a free backend (e.g. Firebase/Supabase).
